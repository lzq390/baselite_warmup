非环片段属性

sulfoxide 是 fragment_010 sulfinyl_group 的属性子类；fragment_022 alkynylene_linkage 覆盖 ethynylene 及其它 C#C 连接环境。

fragment_026 trifluoromethyl 仍作为更具体 core 优先输出；fragment_025 负责剩余卤素取代实例的父级解释，强氟化环境通过 halogen_is_perfluoroalkyl_like 保留。

fragment_023 secondary_amine_linker 仍作为 linker 层级优先输出；它与 fragment_013 amine 是不同解释层级，不合并。

fragment_027-031 是新增结构解释层：thiocarbonyl、N-O、sulfanyl/thiol、silicon center 和 phosphorus center 均与已有功能团/环片段共存，不触发现有 suppression。
